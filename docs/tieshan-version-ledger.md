## C. 八卦加则例的已知边界

2003 年点校本的导读解释涉及年、月、运、日主、六亲、六百律数、卦爻变化等多个环节；乾集开篇还强调每时推八刻、每刻推十五分。仅凭当前已整理的几张映射表，不足以生成可靠的铁板神数总数。

因此程序目前不自动生成命数、六亲定数、考刻结果或人生断语。

## 安身命例规则实现（本轮新增）

依据《康节说易全书·铁板神数》乾集“安身命例”可检索文本行810-817，整理为独立定位步骤：寅宫起正月，顺数至出生农历月份；以该月宫为起点，子时记在起点，按时支逆数安命、顺数安身。

代码函数：`derive_body_life_palaces(lunar_month, hour_branch, leap_month=False)`。

实现边界：
- 必须明确提供农历月份；不得把四柱月柱（节气月）当作农历月份。
- 当前接口仅在请求明确提交 `lunar_month` 时返回身命宫。
- 闰月标记只记录、不自动进位；闰月如何“多一月算”的具体宫位处理，仍待不同版本原文核对。
- 身命宫定位不等于铁板神数定数、考刻或密码条文推演。
- 已增加方向与输入校验测试；尚未在部署环境执行测试。


## 公历/农历输入与换算（本轮新增）

- 前端出生日期改为年、月、日三个联动选择框，支持公历和农历切换。
- 农历月份列表由后端历法库按所选农历年生成，闰月以负月份编码（例如闰二月为 -2），并按该月真实大小月天数生成日期选项。
- 后端采用 6tail/lunar-python（MIT）执行公历/农历转换；转换后的公历日期才进入 Swiss Ephemeris 四柱计算。
- 公历输入会反向换算农历年月日，自动提供安身命宫所需的农历月份，不再让用户手动猜填农历月。
- 当前日期资料范围限制为 1900—2100 年；日期超范围、无效闰月和超出当月天数均应返回校验错误。
- 回归测试覆盖 1986-04-21 农历与 1986-05-29 公历互转、2023 闰二月识别、非法日期拒绝。
- 注意：代码已提交 GitHub；需等待 Render 安装新依赖并部署，再实际验证接口与页面。尚不能宣称线上换算已通过测试。


## 八刻十五分：钟表时间分段（新增基础模块）

依据乾集开篇“每时推八刻、每刻十五分”的说明，新增独立函数
`backend/tieshan_time.py::derive_eight_ke`。按十二时辰各120分钟，将出生地当地钟表时间切分为8个15分钟区间，返回时支、第几刻、区间起止时间。

**严格边界：**
- 目前只是钟表时间的数学分段，不等于传统考刻（通过六亲、事件等校正出生时刻）。
- 暂未进行真太阳时、均时差、历史地方时修正。
- 子时跨日及刻初/刻正的版本差异尚未完成核验。
- 该结果不能单独推出密码数或人生条文。
- 已新增边界测试：子时跨午夜、时辰交界、15分钟区间、时支不匹配及非法时间。



## 铁板神数核心引擎基础架构（2026-11-22）

新增 `backend/tieshan_engine.py`，作为铁板神数专用流程编排层，避免把普通八字细盘误当作铁板神数本体。

当前流程分为：出生资料归档、四柱基础定位、八刻十五分、安身命宫、乾集基础数理表、起数与卦值日月推数、传统考刻、六亲数推演、秘钞密码数与条文定位、一生命运条文汇编。

状态分级：
- `verified`：已实现且有明确来源的基础输入步骤。
- `partial`：仅接入部分规则或数学分段，不代表完整传统方法。
- `blocked`：缺少可逐步复算的原文公式、例题或密码表，禁止输出定数。

API 在四柱计算响应中新增 `iron_plate_engine`，返回版本、流程状态、可用基础资料、规则登记表及停止原因。页面“数理与条文规则状态”同步显示该流程。

本次没有实现最终铁板数、六亲数、考刻结论或人生条文。当前资料仍以2003年现代点校本可检索部分为基础，清刻虚白庐藏本与秘钞密码表尚未取得。后续开发必须先拆解完整例题，逐步验证中间变量，再开放相应阶段。


## 八卦加则例原文结构化拆解（2026-11-22）

依据《康节说易全书·铁板神数》乾集“八卦加则例”及逐句解说，PDF可检索文本行684-715，尤其是解说行699-715。

已将九个句义登记进 `backend/tieshan_classic.py::EIGHT_TRIGRAM_ADDITION_EXPLANATION`：
1. 爻从三十起：原书联系元会运世、年月日时数序、每时三十分钟、三十卦与六亲之数。
2. 乾卦六爻为头：乾为元、为年；年卦以世卦六爻变得。
3. 兑为后少女：兑为会、为月；月在日之后。
4. 只中一网收：原书接续解释年、月，称一年总数从会、月中出。
5. 变知六百止：以六十律数、六亲与十天干解释六百。
6. 应世两同倚：原书以会为世、月为应解释相关数序。
7. 遇十须不用：原书联系先天八卦六十四卦、三百八十四爻。
8. 玄玄妙法周：原书称卦变可以周流变化。
9. 当看多寡数、及止悉因由：查明数值位数规模与计算终止依据。

**算法状态：仅完成原文解释结构化，不可执行数值算法。** 目前仍缺世应定位、年/月卦取法、六亲与十干/六十律数的映射、三十卦逐项演算、“遇十须不用”的逐步舍取位置，以及与坤集条文号衔接的完整例题。页面会展示逐句来源和待验证项，禁止凭个人网络解说擅自补出计算公式。

### 安身命例闰月规则校正

乾集PDF文本行812-817明确写明“若有闰月，作多一月算”，并举例说明闰月按多一月推进。因此 `derive_body_life_palaces` 现按该2003年点校本规则将闰月月份额外进一位；其他版本仍需交叉核对。新增测试验证闰二月按第三个月宫位处理。
