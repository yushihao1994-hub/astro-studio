# 铁板神数版本与规则登记

最后整理：2026-11-22

## A. 当前程序接入的版本

**《康节说易全书·铁板神数》学林出版社 2003 年陈明点校本**

- ISBN：7806684700 / 9787806684702
- Google Books 书目记录：549 页
- 方广古籍网资料页记录：545 页 PDF，目录包含乾集、坤集、子集至戌集。
- 该版是现代点校整理本，不是 2013 年心一堂《清刻足本》影印版。
- 当前可读资料是公开节录、目录和部分公开页面，不代表已经取得或校对了整本 PDF。

## B. 当前只接入可核对的基础对照

1. 天干配卦：壬甲乾、乙癸坤、庚震、辛巽、己离、戊坎、丙艮、丁兑。
2. 地支配卦：亥子坎、寅震、巳午离、丑坤、卯酉乾、辰兑、未申艮、戌巽。
3. 河洛配数：甲己子午九、乙庚丑未八、丙辛寅申七、丁壬卯酉六、戊癸辰戌五、巳亥四。
4. 地支取数类：亥子一六、寅卯三八、巳午二七、申酉四九；辰戌、丑未归五类。此处保留为数类，不替使用者擅自选出唯一数。

## C. 规则边界

书目目录分别列出「天干配卦例」「地支配卦例」「日主配卦例」「河洛配数例」「地支取数例」。程序将这些作为不同规则表，不互相替代。

尚未完成：考刻、八刻十五分校时、完整六亲数算法、卦值日月推数、密码表映射、条文编号检索与实际命例交叉验证。

任何公开节录未覆盖的部分均标记为未核实；不以 AI 补写古籍条文，不把四柱或紫微规则包装成铁板神数原法。
