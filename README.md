# Astro Studio · 星盘研究室

手机优先的中文命理与占星研究工具。仓库包含两个独立入口：

- **铁板神数独立研究版 V1**：出生资料录入、农历/公历转换、四柱基础排盘、命盘资料展示、传统规则资料索引与 DeepSeek 四柱基础文化解读。
- **西方占星研究室**：本命星盘计算与专题报告。

## 直接使用

- 铁板神数 V1：`https://yushihao1994-hub.github.io/astro-studio/tieshan.html`
- 星盘研究室：`https://yushihao1994-hub.github.io/astro-studio/`

## 铁板神数 V1 已包含

- 手机优先的独立网页界面。
- 出生档案：称呼、性别、出生日期、出生时间、出生地点。
- 公历/农历入口，农历闰月单独识别。
- 省、市、县区、乡镇、村级地址逐级选择；自然村可补充填写。
- 出生资料保存在当前设备浏览器，不会因刷新页面自动丢失。
- 后端四柱计算：年柱按立春，月柱按十二节交界，使用出生地点时区。
- 四柱、十神、藏干、五行简单计数、地支关系等基础信息展示。
- 八刻、身命宫及已整理的传统资料索引展示。
- DeepSeek 四柱基础文化解读接口；需在 Render 环境变量配置 `DEEPSEEK_API_KEY`。

## V1 的边界

V1 是可运行的基础研究版，不等于完整铁板神数定数系统。当前 AI 输出明确属于“四柱基础文化解读”，不是完整铁板神数考刻、定数或古籍原文断语。

以下能力不纳入 V1 已完成范围，后续必须按底本证据和可复算规则逐项开发：

- 完整考刻与定数算法。
- 六亲数、秘钞密码表及完整卦序推演。
- 清刻足本全部条文的逐条扫描图核验、组号/条文配对与检索。
- 对未经原图核验的 OCR 候选自动补号或生成断语。

## 后端部署

Render 配置位于 `render.yaml`，服务名为 `astro-studio-api`，健康检查路径为 `/api/health`。部署时需配置：

- `DEEPSEEK_API_KEY`：启用 AI 解读所需。
- 可选：`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`。

前端目前调用 `https://astro-studio-api.onrender.com`。若 Render 服务休眠，首次请求可能需要等待唤醒。

## 本地预览

直接用浏览器打开 `tieshan.html` 可查看页面；完整排盘需要后端 API 正常运行。后端依赖安装：

```bash
pip install -r backend/requirements.txt
cd backend
python app.py
```

## 数据与安全

出生资料默认只保存在当前设备浏览器的 localStorage。不要把真实用户出生档案、访问令牌、API 密钥或密码提交到公开仓库。正式多人使用前，应增加账号隔离、云端加密存储、访问控制与隐私政策。
