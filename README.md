# 星盘研究室（Astro Studio）

手机优先的中文西方占星研究工具。当前仓库包含第一阶段出生资料录入界面。

## 当前实现

- 响应式页面，适配 iPhone Safari、安卓与桌面浏览器
- 出生档案表单：档案名称、日期、当地出生时间、出生地点、时区
- 默认采用热带黄道与 Placidus（普拉西德）宫位系统
- 档案仅保存在当前设备浏览器的 localStorage，不会发送到服务器
- 明确提示真实星历计算尚未接入，不展示虚构星体位置

## 尚未实现

- 地点地理编码与坐标精确度管理
- IANA 时区和夏令时校验、出生当地时间转 UTC
- Swiss Ephemeris 数据文件及许可合规方案
- 行星、交点、四轴、宫头与相位的真实计算 API
- 多用户身份验证、云端私密档案、历史记录
- 星盘图、专业解读报告、PDF/JSON 导出
- HTTPS 正式部署

## 安全说明

仓库目前可能为公开状态。不要提交真实用户出生档案、访问令牌、API 密钥、密码或其他个人敏感信息。示例数据应使用虚构资料。正式上线前应将仓库设为 Private，并建立安全的服务端数据存储与访问控制。

## 本地预览

直接用浏览器打开 `index.html` 即可预览静态界面。此预览不包含星历计算能力。

## 技术路线

1. 静态前端与出生资料校验
2. 后端 API：地点解析、时区处理与真实星历计算
3. 星盘计算结果结构化输出
4. 报告引擎、账户体系与私密档案
5. HTTPS 部署、移动端测试与许可审查
